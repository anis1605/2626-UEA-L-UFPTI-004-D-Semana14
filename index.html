Avance 14/16 - Implementación de un Sistema de Login Funcional

Semana 14: Sistema de Autenticación, Sesiones y Seguridad

Flask-Login 0.6.3 + Werkzeug 3.1

Este avance incorpora el ciclo de vida completo de seguridad y autenticación para el Proyecto Integrador: Registro de usuarios con contraseñas encriptadas mediante generate_password_hash(..., method='scrypt'), Inicio de sesión validado mediante check_password_hash, Control de sesiones con Flask-Login (UserMixin, login_user, current_user), Protección de rutas administrativas mediante @login_required y Cierre seguro de sesión con logout_user().
